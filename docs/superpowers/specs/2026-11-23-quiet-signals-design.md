# 조용한 신호 설계 (시장 인사이트 2a단계 — DART 공시)

- 작성일: 2026-11-23
- 선행: `2026-11-23-sector-thermometer-design.md` (업종 온도계)

## 1. 왜 만드나

큰 뉴스가 되기 전에 회사가 공식적으로 한 일(계약, 설비 투자, 자사주 매입, 증자)은 DART에 먼저 올라온다.
사용자는 "유망한 업종 안에서 어떤 회사에 좋은 신호가 나오는지"를 보면서 판단 연습을 하고 싶어 한다.
1단계 온도계(어느 업종이 유망한가)와 이어지는 **회사 단위의 근거**를 링크와 함께 보여준다.

## 2. 목표 / 비목표

- 목표: 월요일 주간 리포트에 지난 7일의 주요 공시를 최대 15건, 그룹별로 보여준다. 공시마다 "왜 볼까" 한 줄(공시 종류별 고정 문구)과 DART 링크.
- 비목표(이번 단계): 앞으로 뜰 산업(테마) 판단(3단계 AI 의견 — 테마 관련 회사를 이 목록의 그룹으로 추가하는 것도 그때), 뉴스(네이버 — 유망 업종 + 사용자가 고칠 수 있는 테마 키워드 목록)·수출 통계(2b단계), 공시 본문 파싱(계약 금액·매출 대비 비율), 임원 매수·5% 대량보유(제목만으로 매수/매도 구분 불가), AI 의견(3단계).
- 하면 안 되는 것: 공시를 "사라"는 신호로 표현하는 것. AI가 문구를 만드는 것.

## 3. 접근 방식

| 안 | 내용 | 결과 |
|---|---|---|
| A. 온도계 연결 | 보유 종목 + 유망 업종 소속 회사만 | 업종 흐름과 이어지지만 큰 회사의 중요한 공시를 놓침 |
| B. 큰 회사 | 시가총액 상위 300 + 보유 종목 | 단순하지만 업종 흐름과 따로 놂 |
| C. 종류로만 | 종류별 규칙으로 거름 | 기준이 자의적 |
| **A+B (선택)** | 보유 종목 + 유망 업종 회사 + 시총 상위 300 | 사용자가 "유망한 업종 중에서, 둘 다"를 원함 |

## 4. 대상과 규칙

- **유망 업종**(코드 판단, 국내만): 온도계 행 중 `earnings_1y_pct > 0` 이고 `level`이 "싸요" 또는 "보통"인 업종. "이익이 늘고 있고 아직 비싸지 않은 업종". 정점 주의 문구가 붙은 업종도 포함하되 그 표시가 함께 보인다.
- **대상 회사**: 보유 국내 종목 ∪ 유망 업종 소속 회사(KRX `get_index_portfolio_deposit_file`) ∪ 시가총액 상위 300(KRX `get_market_cap(market="ALL")`).
- **공시 종류**(DART `list.json`, 시장 전체, 지난 7일, 공시유형 B·I, 제목에 "정정"이 들어간 것 제외):

| 종류 | 제목 키워드 | 왜 볼까 (고정 문구) | 성격 |
|---|---|---|---|
| contract | 단일판매ㆍ공급계약체결 / 공급계약 | 계약은 앞으로 매출이 늘어날 근거예요 | 좋은 신호 |
| facility | 신규시설투자 | 회사가 수요가 늘 거라고 자신할 때 설비를 늘려요 | 좋은 신호 |
| buyback | 자기주식취득 (결정·신탁계약) | 회사가 스스로 주가가 싸다고 볼 때 자사주를 사요 | 좋은 신호 |
| rights_issue | 유상증자결정 | 주식 수가 늘어 기존 주주 몫이 줄 수 있어요 | 주의 |

- **그룹과 순서**: 보유 → 유망 업종 → 큰 회사(한 회사가 여러 그룹이면 앞 그룹). 그룹 안에서는 최신순. 최대 15건, 나머지는 "외 N건".
- 같은 회사·같은 종류가 여러 건이면 최신 1건만.

## 5. 실패 처리

- 월요일·업종 온도계를 수집한 실행에서만 동작.
- KRX(소속 회사·시가총액) 실패 → 해당 그룹만 빠지고 `signals_missing`에 한 줄. DART 실패 → 섹션 전체가 누락 한 줄.
- KRX 조회 날짜: 오늘 이전 가장 최근 거래일(최대 7일 거슬러 올라가며 빈 결과면 하루 전).

## 6. 데이터 구조

- `report/schema.py`: `QuietSignal{ticker, name, kind, title, date, url, group("holding"|"promising"|"large"), sector: str|None, why}`,
  `Context.signals: list[QuietSignal]`, `Context.signals_more: int = 0`, `Context.signals_missing: list[str]`, `Context.promising_sectors: list[str]`.

## 9. 테스트

- 분류: 키워드별 종류, 정정 제외, 해당 없음
- 유망 업종: 이익 +·비싸지 않음만, 레벨 없음 제외, 미국 제외
- 선택: 그룹 우선순위, 중복 회사 앞 그룹, 같은 회사·종류 최신 1건, 15건 상한과 "외 N건", 최신순
- 수집: DART 페이지 전부 읽기, KRX 실패 시 그룹만 누락, DART 실패 시 섹션 누락, 월요일 아니면 없음
- 렌더: 주간에만, 신호 없으면 섹션 없음, 주의 표시, 링크
- live: 실제 `market_disclosures` 1주, `kr_constituents`, `market_cap_top`

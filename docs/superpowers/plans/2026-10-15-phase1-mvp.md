# 1단계(MVP) 구현 계획: 국내 보유 종목 숫자 리포트 메일

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `holdings.yaml`의 국내 보유 종목에 대해 DART 재무·공시와 시세로 지표·PER/PBR 밴드 가격·판단 신호·포트폴리오 점검을 계산하고, 그 결과를 HTML 메일(또는 dry-run 미리보기)로 보낸다.

**Architecture:** `collectors/`(DART·시세)가 원자료를 가져오고, `analysis/`의 순수 함수들이 모든 숫자를 계산하며, `report/context.py`가 이를 `context.json`(pydantic `Context`)으로 묶는다. `publish`는 선택적으로 `analysis.json`(AI 작성, 3단계부터)을 검증해 합치고, Jinja2로 메일 HTML을 렌더링해 SMTP(기본: 네이버 메일)로 보낸다. 1단계에는 AI 단계가 없으므로 기본 출력은 "숫자 리포트"다.

**Tech Stack:** Python 3.12+, uv, httpx, pandas, pykrx(국내 일봉), yfinance(미국·환율·지수), pydantic v2, Jinja2, PyYAML, python-dotenv, tzdata, pytest

**Spec:** `docs/superpowers/specs/2026-10-15-trading-ai-agent-design.md`

## Global Constraints

- Python `>=3.12`, 패키지 관리는 `uv` (`uv sync --extra dev`, `uv run pytest`)
- 날짜는 항상 한국시간(KST, `Asia/Seoul`) 기준 — Routine은 UTC 서버에서 돈다
- 모든 가격·지표는 코드가 계산한다. 리포트에 코드가 계산하지 않은 숫자가 들어가면 안 된다
- 선택 소스(수급 등)는 키·계정이 없거나 실패해도 리포트 생성이 멈추지 않는다
- 신호 값은 `add`(추가매수) / `hold`(보유) / `trim`(일부매도) / `review`(재검토), 우선순위 review > trim > add > hold
- 성향 기준값(균형형 B): 재검토 하락폭 15%, 단일 종목 최대 비중 15%, 자산군 허용 오차 5%p, 분할매수 3회
- 목표 비중 기본값: 국내 30 / 미국 40 / 지수 30 (합 100이어야 함)
- 사용자에게 보이는 문구는 한국어
- 비밀 정보는 환경변수(`.env`, git 제외)로만. 코드·설정 파일에 키를 쓰지 않는다
- KRX 로그인 없이 동작해야 한다: pykrx는 `get_market_ohlcv`(일봉)만 사용. 시가총액은 DART 발행주식수 × 종가로 계산. 수급(`get_market_trading_value_by_date`)은 `KRX_ID`/`KRX_PW`가 있을 때만 시도

## Review Focus

1. **따옴표 없는 종목코드** (`ticker: 000660`) — YAML이 8진수 정수 432로 읽는다. "따옴표로 감싸라"는 오류가 나야 한다 → Task 1 테스트
2. **연결재무제표가 없는 회사 / 누적금액 필드가 없는 보고서** — CFS가 없으면 OFS로, `thstrm_add_amount`가 없으면 `thstrm_amount`로 대체해야 한다 → Task 3, Task 8 테스트
3. **적자 기업·금융업** — PER이 의미 없으므로 PER은 비우고 PBR 밴드로 가격을 내야 하며, 금융업은 부채비율 조건 때문에 추가매수가 영원히 막히면 안 된다 → Task 4, 5, 6 테스트
4. **한 종목 시세 실패** — 그 종목만 "데이터 누락"으로 표시하고 나머지 종목과 포트폴리오 계산은 계속돼야 한다 → Task 10 테스트
5. **UTC 서버에서 07:00 KST 실행** — 날짜가 하루 전으로 찍히면 안 된다 → Task 1 테스트

"""설정·보유 종목 YAML 로딩과 한국시간 날짜."""
from datetime import date, datetime
from pathlib import Path
from typing import Literal
from zoneinfo import ZoneInfo

import yaml
from pydantic import BaseModel, field_validator, model_validator

KST = ZoneInfo("Asia/Seoul")

AssetClass = Literal["domestic", "us", "index"]


class Profile(BaseModel):
    name: str = "balanced"
    review_drawdown_pct: float = 15
    max_single_weight_pct: float = 15
    rebalance_band_pct: float = 5
    buy_tranches: Literal[3] = 3


class Settings(BaseModel):
    profile: Profile = Profile()
    target_allocation: dict[AssetClass, float] = {"domestic": 30, "us": 40, "index": 30}
    band_years: int = 5
    min_band_points: int = 36
    disclosure_days: int = 7
    report_subject_prefix: str = "[투자 리포트]"

    @model_validator(mode="after")
    def _allocation_sums_to_100(self):
        total = sum(self.target_allocation.values())
        if abs(total - 100) > 0.01:
            raise ValueError(f"target_allocation 합계가 100이 아닙니다: {total}")
        return self


class Position(BaseModel):
    ticker: str
    name: str | None = None
    qty: float
    avg_price: float

    @field_validator("ticker", mode="before")
    @classmethod
    def _ticker_must_be_string(cls, value):
        if not isinstance(value, str):
            raise ValueError(f'종목코드 {value!r}는 따옴표로 감싸야 합니다 (예: ticker: "000660")')
        return value.strip()


class Account(BaseModel):
    name: str
    broker: str
    market: Literal["KR", "US"]
    asset_class: AssetClass
    analyze: bool = True
    positions: list[Position]


class Holdings(BaseModel):
    accounts: list[Account]
    cash_krw: float = 0


def _read_yaml(path: Path) -> dict:
    with open(path, encoding="utf-8") as f:
        return yaml.safe_load(f) or {}


def load_settings(path: Path) -> Settings:
    return Settings.model_validate(_read_yaml(path))


def load_holdings(path: Path) -> Holdings:
    return Holdings.model_validate(_read_yaml(path))


def today_kst(now: datetime | None = None) -> date:
    now = now or datetime.now(KST)
    return now.astimezone(KST).date()
```

"""가격 시계열 기반 기술 지표 (매매 시점 보조 근거용)."""
import pandas as pd


def moving_average(close: pd.Series, window: int) -> float | None:
    if len(close) < window:
        return None
    return float(close.iloc[-window:].mean())


def rsi(close: pd.Series, period: int = 14) -> float | None:
    """Wilder 방식 RSI."""
    if len(close) <= period:
        return None
    delta = close.diff().dropna()
    gain = delta.clip(lower=0)
    loss = -delta.clip(upper=0)
    avg_gain = gain.ewm(alpha=1 / period, adjust=False).mean().iloc[-1]
    avg_loss = loss.ewm(alpha=1 / period, adjust=False).mean().iloc[-1]
    if avg_loss == 0:
        return 100.0
    return float(100 - 100 / (1 + avg_gain / avg_loss))


def position_in_52w(close: pd.Series) -> float | None:
    window = close.iloc[-252:]
    if len(window) < 2:
        return None
    low, high = window.min(), window.max()
    if high == low:
        return 50.0
    return float((close.iloc[-1] - low) / (high - low) * 100)
```

DART `fnlttSinglAcntAll` 응답 메모: 손익계산서(`sj_div` = `IS` 또는 `CIS`)에서 분기·반기 보고서는 `thstrm_amount`가 3개월치, `thstrm_add_amount`가 연초부터 누적이다. 사업보고서(4분기)는 `thstrm_add_amount`가 없고 `thstrm_amount`가 연간 합계다. 그래서 "누적값(add 우선, 없으면 thstrm)"을 구한 뒤 직전 분기 누적과의 차이로 분기값을 만든다. 재무상태표(`BS`)는 `thstrm_amount`가 분기말 잔액이다.

    """DART fnlttSinglAcntAll 응답의 list 항목 모양을 흉내낸다."""

    def flow(account_id, name, cum):

"""DART 재무제표 응답 → 분기 실적·TTM (순수 함수)."""
from dataclasses import dataclass
from datetime import date

REPORT_CODES = {1: "11013", 2: "11012", 3: "11014", 4: "11011"}

# (우선 account_id 목록, 대체 account_nm 목록)
FLOW_ACCOUNTS = {
    "revenue": (["ifrs-full_Revenue"], ["매출액", "수익(매출액)", "영업수익", "매출"]),
    "op": (["dart_OperatingIncomeLoss"], ["영업이익", "영업이익(손실)"]),
    "ni": (
        ["ifrs-full_ProfitLossAttributableToOwnersOfParent", "ifrs-full_ProfitLoss"],
        ["지배기업의 소유주에게 귀속되는 당기순이익", "당기순이익", "당기순이익(손실)"],
    ),
}
STOCK_ACCOUNTS = {
    "equity_owners": (
        ["ifrs-full_EquityAttributableToOwnersOfParent", "ifrs-full_Equity"],
        ["지배기업의 소유주에게 귀속되는 자본", "자본총계"],
    ),
    "equity_total": (["ifrs-full_Equity"], ["자본총계"]),
    "liabilities": (["ifrs-full_Liabilities"], ["부채총계"]),
}


def quarter_end(year: int, quarter: int) -> date:
    month = quarter * 3
    return date(year, month, 31 if month in (3, 12) else 30)


@dataclass(frozen=True)
class QuarterFigures:
    year: int
    quarter: int
    revenue: float | None
    op_income: float | None
    net_income: float | None
    equity_owners: float | None
    equity_total: float | None
    liabilities: float | None

    @property
    def period_end(self) -> date:
        return quarter_end(self.year, self.quarter)


def parse_amount(text) -> float | None:
    if text is None:
        return None
    s = str(text).strip().replace(",", "")
    if s in ("", "-"):
        return None
    negative = s.startswith("(") and s.endswith(")")
    try:
        value = float(s.strip("()"))
    except ValueError:
        return None
    return -value if negative else value


def _normalize(name: str) -> str:
    return name.replace(" ", "")


def _find(rows, sj_divs, ids, names, getter):
    candidates = [r for div in sj_divs for r in rows if r.get("sj_div") == div]
    for account_id in ids:
        for r in candidates:
            if r.get("account_id") == account_id:
                value = getter(r)
                if value is not None:
                    return value
    wanted = [_normalize(n) for n in names]
    for name in wanted:
        for r in candidates:
            if _normalize(r.get("account_nm", "")) == name:
                value = getter(r)
                if value is not None:
                    return value
    return None


def _cumulative(row):
    value = parse_amount(row.get("thstrm_add_amount"))
    return value if value is not None else parse_amount(row.get("thstrm_amount"))


def _period_end_value(row):
    return parse_amount(row.get("thstrm_amount"))


def extract_report(rows: list[dict]) -> dict[str, float | None]:
    out = {}
    for key, (ids, names) in FLOW_ACCOUNTS.items():
        out[key] = _find(rows, ("IS", "CIS"), ids, names, _cumulative)
    for key, (ids, names) in STOCK_ACCOUNTS.items():
        out[key] = _find(rows, ("BS",), ids, names, _period_end_value)
    return out


def build_quarters(reports: dict[tuple[int, int], list[dict]]) -> list[QuarterFigures]:
    extracted = {k: extract_report(v) for k, v in reports.items()}
    result = []
    for year, quarter in sorted(extracted):
        cur = extracted[(year, quarter)]
        prev = extracted.get((year, quarter - 1)) if quarter > 1 else None

        def flow(key):
            if cur[key] is None:
                return None
            if quarter == 1:
                return cur[key]
            if prev is None or prev[key] is None:
                return None
            return cur[key] - prev[key]

        result.append(QuarterFigures(
            year=year, quarter=quarter,
            revenue=flow("revenue"), op_income=flow("op"), net_income=flow("ni"),
            equity_owners=cur["equity_owners"], equity_total=cur["equity_total"], liabilities=cur["liabilities"],
        ))
    return result


def ttm(quarters: list[QuarterFigures], index: int) -> dict[str, float | None]:
    """index 분기를 끝으로 하는 연속 4개 분기 합. 연속이 아니거나 값이 빠지면 None."""
    keys = ("revenue", "op_income", "net_income")
    if index < 3:
        return dict.fromkeys(keys)
    window = quarters[index - 3:index + 1]
    ordinals = [q.year * 4 + q.quarter for q in window]
    if ordinals != list(range(ordinals[0], ordinals[0] + 4)):
        return dict.fromkeys(keys)
    out = {}
    for key in keys:
        values = [getattr(q, key) for q in window]
        out[key] = None if any(v is None for v in values) else sum(values)
    return out
```

"""PER·PBR·ROE 등 재무 지표 계산."""
from agent.analysis.financials import QuarterFigures, ttm
from agent.report.schema import Fundamentals


def _pct(numer, denom):
    if numer is None or denom is None or denom <= 0:
        return None
    return numer / denom * 100


def _yoy(current, base):
    if current is None or base is None or base <= 0:
        return None
    return (current - base) / base * 100


def compute_fundamentals(quarters: list[QuarterFigures], market_cap: float, close: float,
                         dps: float | None) -> Fundamentals:
    if not quarters:
        return Fundamentals()
    index = len(quarters) - 1
    latest = quarters[index]
    t = ttm(quarters, index)
    ni = t["net_income"]
    base = next((x for x in quarters if (x.year, x.quarter) == (latest.year - 1, latest.quarter)), None)
    equity = latest.equity_owners
    return Fundamentals(
        per=market_cap / ni if ni is not None and ni > 0 else None,
        pbr=market_cap / equity if equity is not None and equity > 0 else None,
        roe=_pct(ni, equity),
        op_margin=_pct(t["op_income"], t["revenue"]),
        rev_yoy=_yoy(latest.revenue, base.revenue if base else None),
        op_yoy=_yoy(latest.op_income, base.op_income if base else None),
        debt_ratio=_pct(latest.liabilities, latest.equity_total),
        div_yield=dps / close * 100 if dps is not None and close > 0 else None,
        ttm_net_income=ni,
        latest_quarter=f"{latest.year}Q{latest.quarter}",
    )

"""PER/PBR 밴드 기반 적정가·분할매수가·매도목표가·재검토가."""
from typing import Literal

import pandas as pd

from agent.analysis.financials import QuarterFigures, ttm
from agent.config import Profile
from agent.report.schema import Band, Valuation

FINANCIAL_KSIC_PREFIXES = ("64", "65", "66")


def is_financial(induty_code: str | None) -> bool:
    return bool(induty_code) and induty_code.startswith(FINANCIAL_KSIC_PREFIXES)


def choose_method(financial: bool, ttm_net_income: float | None) -> Literal["PER", "PBR"]:
    if financial or ttm_net_income is None or ttm_net_income <= 0:
        return "PBR"
    return "PER"


def monthly_multiples(monthly_close: pd.Series, quarters: list[QuarterFigures], shares: float,
                      method: str, lag_days: int = 60) -> pd.Series:
    denominators = []
    for i, q in enumerate(quarters):
        value = ttm(quarters, i)["net_income"] if method == "PER" else q.equity_owners
        available_from = pd.Timestamp(q.period_end) + pd.Timedelta(days=lag_days)
        denominators.append((available_from, value))

    out = {}
    for month_end, close in monthly_close.items():
        available = [value for available_from, value in denominators if available_from <= month_end]
        if not available:
            continue
        denom = available[-1]
        if denom is None or denom <= 0:
            continue
        out[month_end] = float(close) * shares / denom
    return pd.Series(out, dtype=float)


def band_valuation(multiples: pd.Series, method: str, current_multiple: float | None, close: float,
                   avg_price: float | None, profile: Profile, band_years: int, min_points: int,
                   decimals: int = 0) -> Valuation:
    def rnd(x):
        return round(x, decimals) if decimals else round(x)

    review = rnd(avg_price * (1 - profile.review_drawdown_pct / 100)) if avg_price else None
    recent = multiples.iloc[-band_years * 12:]
    if current_multiple is None or current_multiple <= 0 or len(recent) < min_points:
        return Valuation(method=method, insufficient=True, review=review,
                         note=f"{method} 밴드 계산에 필요한 데이터 부족 ({len(recent)}개월, 최소 {min_points}개월)")

    p10, p25, p50, p75, p90 = (float(recent.quantile(x)) for x in (0.10, 0.25, 0.50, 0.75, 0.90))

    def price(multiple):
        return rnd(close * multiple / current_multiple)

    return Valuation(
        method=method,
        insufficient=False,
        current_multiple=round(current_multiple, 2),
        band=Band(p10=round(p10, 2), p25=round(p25, 2), p50=round(p50, 2), p75=round(p75, 2), p90=round(p90, 2)),
        fair=price(p50),
        buy=[price(p25), price((p10 + p25) / 2), price(p10)],
        sell=[price(p75), price(p90)],
        review=review,
    )
```

"""판단 신호: review > trim > add > hold."""
from agent.config import Profile
from agent.report.schema import Fundamentals, Signal, Valuation


def decide_signal(close: float, valuation: Valuation, fundamentals: Fundamentals, weight_pct: float,
                  profile: Profile, negative_disclosure: bool, financial: bool = False) -> tuple[Signal, list[str]]:
    review_reasons = []
    if valuation.review is not None and close <= valuation.review:
        review_reasons.append("재검토 기준가 이하")
    if negative_disclosure:
        review_reasons.append("최근 악재 유형 공시")
    if review_reasons:
        return "review", review_reasons

    trim_reasons = []
    if not valuation.insufficient and close >= valuation.sell[0]:
        trim_reasons.append("일부매도 1차 목표가 도달")
    if weight_pct > profile.max_single_weight_pct:
        trim_reasons.append("단일 종목 최대 비중 초과")
    if trim_reasons:
        return "trim", trim_reasons

    debt_ok = financial or (fundamentals.debt_ratio is not None and fundamentals.debt_ratio < 200)
    if (not valuation.insufficient
            and close <= valuation.buy[0]
            and fundamentals.op_yoy is not None and fundamentals.op_yoy > -30
            and debt_ok
            and weight_pct < profile.max_single_weight_pct):
        return "add", ["분할매수 1단계 가격 이하", "실적·재무 조건 충족"]

    return "hold", []
```

"""보유 합산, 원화 평가액, 비중, 리밸런싱 제안."""
from dataclasses import dataclass

from agent.config import Holdings, Settings
from agent.report.schema import ClassWeight, Portfolio, Rebalance

CLASS_LABELS = {"domestic": "국내", "us": "미국", "index": "지수"}


def position_key(market: str, ticker: str) -> str:
    return f"{market}:{ticker}"


@dataclass
class AggregatedPosition:
    key: str
    ticker: str
    name: str
    market: str
    asset_class: str
    qty: float
    avg_price: float
    analyze: bool


@dataclass
class PositionValue:
    position: AggregatedPosition
    close: float | None
    value_krw: float | None


def aggregate_positions(holdings: Holdings) -> list[AggregatedPosition]:
    merged: dict[str, AggregatedPosition] = {}
    for account in holdings.accounts:
        for p in account.positions:
            key = position_key(account.market, p.ticker)
            if key not in merged:
                merged[key] = AggregatedPosition(key, p.ticker, p.name or p.ticker, account.market,
                                                 account.asset_class, p.qty, p.avg_price, account.analyze)
                continue
            m = merged[key]
            total_qty = m.qty + p.qty
            m.avg_price = (m.avg_price * m.qty + p.avg_price * p.qty) / total_qty if total_qty else 0
            m.qty = total_qty
            m.analyze = m.analyze or account.analyze
    return list(merged.values())


def value_positions(positions: list[AggregatedPosition], closes: dict[str, float],
                    usdkrw: float | None) -> list[PositionValue]:
    out = []
    for p in positions:
        close = closes.get(p.key)
        fx = 1.0 if p.market == "KR" else usdkrw
        value = p.qty * close * fx if close is not None and fx else None
        out.append(PositionValue(p, close, value))
    return out


def summarize(values: list[PositionValue], cash_krw: float, settings: Settings) -> Portfolio:
    warnings = [f"{v.position.name}: 시세 없음 — 비중 계산에서 제외" for v in values if v.value_krw is None]
    priced = [v for v in values if v.value_krw is not None]
    total = sum(v.value_krw for v in priced) + cash_krw
    if total <= 0:
        return Portfolio(total_krw=0, cash_krw=cash_krw, warnings=warnings + ["평가금액이 0원입니다"])

    weights = {v.position.key: v.value_krw / total * 100 for v in priced}
    by_class, rebalance = {}, []
    band = settings.profile.rebalance_band_pct
    for cls, target in settings.target_allocation.items():
        value = sum(v.value_krw for v in priced if v.position.asset_class == cls)
        pct = value / total * 100
        diff = pct - target
        by_class[cls] = ClassWeight(label=CLASS_LABELS[cls], value_krw=value, pct=pct,
                                    target_pct=target, diff_pct=diff)
        if abs(diff) > band:
            rebalance.append(Rebalance(asset_class=cls, label=CLASS_LABELS[cls],
                                       action="줄이기" if diff > 0 else "늘리기",
                                       amount_krw=round(abs(diff) / 100 * total, -4)))

    limit = settings.profile.max_single_weight_pct
    for v in priced:
        weight = weights[v.position.key]
        if weight > limit and v.position.asset_class != "index":
            warnings.append(f"{v.position.name} 비중 {weight:.1f}% — 단일 종목 최대 {limit:.0f}% 초과")

    return Portfolio(total_krw=total, cash_krw=cash_krw, by_class=by_class, rebalance=rebalance,
                     warnings=warnings, weights=weights)
```

"""OpenDART API 클라이언트 (https://opendart.fss.or.kr)."""
import io
import json
import time
import xml.etree.ElementTree as ET
import zipfile
from datetime import date
from pathlib import Path

import httpx

from agent.analysis.financials import REPORT_CODES, parse_amount, quarter_end

BASE_URL = "https://opendart.fss.or.kr/api"
CORP_CODE_MAX_AGE_SEC = 7 * 24 * 3600


class DartError(RuntimeError):
    pass


def disclosure_url(rcept_no: str) -> str:
    return f"https://dart.fss.or.kr/dsaf001/main.do?rcpNo={rcept_no}"


class DartClient:
    def __init__(self, api_key: str, cache_dir: Path, http: httpx.Client | None = None,
                 today: date | None = None):
        self.api_key = api_key
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)
        self.http = http or httpx.Client(timeout=30, transport=httpx.HTTPTransport(retries=2))
        self.today = today or date.today()
        self._corp_codes: dict[str, str] | None = None

    def _get_json(self, endpoint: str, **params) -> dict | None:
        resp = self.http.get(f"{BASE_URL}/{endpoint}", params={"crtfc_key": self.api_key, **params})
        resp.raise_for_status()
        data = resp.json()
        status = data.get("status")
        if status == "013":
            return None
        if status != "000":
            raise DartError(f"{endpoint}: {status} {data.get('message', '')}")
        return data

    def _load_corp_codes(self) -> dict[str, str]:
        cache = self.cache_dir / "corp_codes.json"
        if cache.exists() and time.time() - cache.stat().st_mtime < CORP_CODE_MAX_AGE_SEC:
            return json.loads(cache.read_text(encoding="utf-8"))
        resp = self.http.get(f"{BASE_URL}/corpCode.xml", params={"crtfc_key": self.api_key})
        resp.raise_for_status()
        with zipfile.ZipFile(io.BytesIO(resp.content)) as zf:
            root = ET.fromstring(zf.read(zf.namelist()[0]))
        codes = {}
        for el in root.iter("list"):
            stock_code = (el.findtext("stock_code") or "").strip()
            if stock_code:
                codes[stock_code] = el.findtext("corp_code").strip()
        cache.write_text(json.dumps(codes), encoding="utf-8")
        return codes

    def corp_code(self, stock_code: str) -> str:
        if self._corp_codes is None:
            self._corp_codes = self._load_corp_codes()
        try:
            return self._corp_codes[stock_code]
        except KeyError:
            raise DartError(f"DART에서 종목코드 {stock_code}를 찾을 수 없습니다") from None

    def company(self, corp_code: str) -> dict:
        return self._get_json("company.json", corp_code=corp_code) or {}

    def financial_rows(self, corp_code: str, year: int, quarter: int) -> list[dict] | None:
        cache = self.cache_dir / f"fin_{corp_code}_{year}_{quarter}.json"
        if cache.exists():
            return json.loads(cache.read_text(encoding="utf-8"))
        rows = None
        for fs_div in ("CFS", "OFS"):
            data = self._get_json("fnlttSinglAcntAll.json", corp_code=corp_code, bsns_year=str(year),
                                  reprt_code=REPORT_CODES[quarter], fs_div=fs_div)
            if data and data.get("list"):
                rows = data["list"]
                break
        if rows is not None and year < self.today.year:
            cache.write_text(json.dumps(rows, ensure_ascii=False), encoding="utf-8")
        return rows

    def _past_periods(self, start_year: int) -> list[tuple[int, int]]:
        return [(y, q) for y in range(start_year, self.today.year + 1) for q in range(1, 5)
                if quarter_end(y, q) <= self.today]

    def quarterly_reports(self, corp_code: str, years: int) -> dict[tuple[int, int], list[dict]]:
        out = {}
        for year, quarter in self._past_periods(self.today.year - years):
            rows = self.financial_rows(corp_code, year, quarter)
            if rows:
                out[(year, quarter)] = rows
        return out

    def shares_outstanding(self, corp_code: str) -> float | None:
        for year, quarter in reversed(self._past_periods(self.today.year - 2)):
            data = self._get_json("stockTotqySttus.json", corp_code=corp_code, bsns_year=str(year),
                                  reprt_code=REPORT_CODES[quarter])
            for row in (data or {}).get("list", []):
                if row.get("se", "").replace(" ", "") == "보통주":
                    value = parse_amount(row.get("istc_totqy"))
                    if value:
                        return value
        return None

    def dividend_per_share(self, corp_code: str) -> float | None:
        for year in (self.today.year - 1, self.today.year - 2):
            data = self._get_json("alotMatter.json", corp_code=corp_code, bsns_year=str(year),
                                  reprt_code=REPORT_CODES[4])
            for row in (data or {}).get("list", []):
                if ("주당현금배당금" in row.get("se", "").replace(" ", "")
                        and row.get("stock_knd") in (None, "", "보통주")):
                    return parse_amount(row.get("thstrm")) or 0.0
        return None

    def disclosures(self, corp_code: str, start: date, end: date) -> list[dict]:
        data = self._get_json("list.json", corp_code=corp_code, bgn_de=start.strftime("%Y%m%d"),
                              end_de=end.strftime("%Y%m%d"), page_count="100")
        return (data or {}).get("list", [])
```

"""시세: 국내는 pykrx 일봉, 미국·환율·지수는 yfinance."""
import os
from datetime import date, timedelta

import pandas as pd

INDEX_TICKERS = {"KOSPI": "^KS11", "KOSDAQ": "^KQ11", "S&P500": "^GSPC", "NASDAQ": "^IXIC", "VIX": "^VIX"}


def _yyyymmdd(d: date) -> str:
    return d.strftime("%Y%m%d")


class MarketData:
    def kr_closes(self, ticker: str, start: date, end: date) -> pd.Series:
        from pykrx import stock

        df = stock.get_market_ohlcv(_yyyymmdd(start), _yyyymmdd(end), ticker)
        if df is None or df.empty or "종가" not in df.columns:
            raise RuntimeError(f"{ticker} 국내 시세를 가져오지 못했습니다")
        closes = df["종가"].astype(float)
        return closes[closes > 0]

    def us_closes(self, ticker: str, start: date, end: date) -> pd.Series:
        import yfinance as yf

        df = yf.Ticker(ticker).history(start=start.isoformat(), end=(end + timedelta(days=1)).isoformat(),
                                       auto_adjust=True)
        if df is None or df.empty:
            raise RuntimeError(f"{ticker} 시세를 가져오지 못했습니다")
        closes = df["Close"].astype(float)
        closes.index = closes.index.tz_localize(None)
        return closes

    def usdkrw(self, today: date) -> float:
        return float(self.us_closes("KRW=X", today - timedelta(days=10), today).iloc[-1])

    def indices(self, today: date) -> dict[str, dict]:
        out = {}
        for name, ticker in INDEX_TICKERS.items():
            try:
                closes = self.us_closes(ticker, today - timedelta(days=10), today)
            except Exception:
                continue
            change = (closes.iloc[-1] / closes.iloc[-2] - 1) * 100 if len(closes) >= 2 else None
            out[name] = {"close": float(closes.iloc[-1]), "change_pct": None if change is None else float(change)}
        return out

    def kr_flows(self, ticker: str, end: date) -> dict | None:
        if not (os.getenv("KRX_ID") and os.getenv("KRX_PW")):
            return None
        from pykrx import stock

        df = stock.get_market_trading_value_by_date(_yyyymmdd(end - timedelta(days=14)), _yyyymmdd(end), ticker)
        if df is None or df.empty:
            return None
        last5 = df.tail(5)
        return {"foreign_5d_krw": float(last5["외국인합계"].sum()),
                "institution_5d_krw": float(last5["기관합계"].sum())}
```

def price_snapshot(closes: pd.Series) -> PriceSnapshot:
    return PriceSnapshot(
        close=float(closes.iloc[-1]),
        price_date=closes.index[-1].date().isoformat(),
        ma20=moving_average(closes, 20),
        ma60=moving_average(closes, 60),
        ma120=moving_average(closes, 120),
        rsi14=rsi(closes),
        pos_52w_pct=position_in_52w(closes),
    )


def _market(market, today: date) -> Market:
    m = Market()
    try:
        m.fx_usdkrw = market.usdkrw(today)
    except Exception as e:
        m.missing.append(f"환율: {e}")
    try:
        m.indices = {name: IndexQuote(**q) for name, q in market.indices(today).items()}
    except Exception as e:
        m.missing.append(f"지수: {e}")
    return m


def _fetch_closes(market, p: AggregatedPosition, start: date, today: date) -> pd.Series:
    if p.market == "KR":
        return market.kr_closes(p.ticker, start, today)
    return market.us_closes(p.ticker, start, today)


def _analyze_kr(h: HoldingContext, closes: pd.Series, market, dart, settings: Settings, today: date) -> None:
    corp = dart.corp_code(h.ticker)
    company = dart.company(corp)
    quarters = build_quarters(dart.quarterly_reports(corp, years=settings.band_years + 1))
    shares = dart.shares_outstanding(corp)
    if not quarters or not shares:
        raise RuntimeError("재무제표 또는 발행주식수를 찾지 못했습니다")

    close = h.price.close
    h.fundamentals = compute_fundamentals(quarters, close * shares, close, dart.dividend_per_share(corp))
    h.financial_sector = is_financial(company.get("induty_code"))
    method = choose_method(h.financial_sector, h.fundamentals.ttm_net_income)
    monthly = closes.resample("ME").last().dropna()
    multiples = monthly_multiples(monthly, quarters, shares, method)
    current = h.fundamentals.per if method == "PER" else h.fundamentals.pbr
    h.valuation = band_valuation(multiples, method, current, close, h.position.avg_price, settings.profile,
                                 settings.band_years, settings.min_band_points)

    for row in dart.disclosures(corp, today - timedelta(days=settings.disclosure_days), today):
        category, negative = classify(row["report_nm"])
        d = row["rcept_dt"]
        h.disclosures.append(Disclosure(date=f"{d[:4]}-{d[4:6]}-{d[6:]}", title=row["report_nm"],
                                        category=category, negative=negative,
                                        url=disclosure_url(row["rcept_no"])))

    try:
        flows = market.kr_flows(h.ticker, today)
        h.flows = Flows(**flows) if flows else None
    except Exception as e:
        h.missing.append(f"수급: {e}")

    h.signal, h.signal_reasons = decide_signal(
        close, h.valuation, h.fundamentals, h.position.weight_pct or 0, settings.profile,
        any(d.negative for d in h.disclosures), h.financial_sector)


def build_context(settings: Settings, holdings: Holdings, market, dart, today: date) -> Context:
    market_info = _market(market, today)
    positions = aggregate_positions(holdings)
    start = today - timedelta(days=365 * (settings.band_years + 1))

    series: dict[str, pd.Series] = {}
    errors: dict[str, str] = {}
    for p in positions:
        try:
            series[p.key] = _fetch_closes(market, p, start, today)
        except Exception as e:
            log.warning("시세 실패 %s: %s", p.key, e)
            errors[p.key] = str(e)
    if not series:
        raise ContextError("모든 종목의 시세를 가져오지 못했습니다")

    closes = {key: float(s.iloc[-1]) for key, s in series.items()}
    portfolio = summarize(value_positions(positions, closes, market_info.fx_usdkrw), holdings.cash_krw, settings)

    holding_contexts = []
    for p in positions:
        h = HoldingContext(ticker=p.ticker, name=p.name, market=p.market, asset_class=p.asset_class,
                           position=PositionInfo(qty=p.qty, avg_price=p.avg_price,
                                                 weight_pct=portfolio.weights.get(p.key)))
        holding_contexts.append(h)
        if p.key in errors:
            h.missing.append(f"시세: {errors[p.key]}")
            continue
        h.price = price_snapshot(series[p.key])
        if not p.analyze:
            continue
        if p.market == "US":
            h.missing.append("미국 종목 분석은 2단계에서 추가됩니다")
            continue
        try:
            _analyze_kr(h, series[p.key], market, dart, settings, today)
        except Exception as e:
            log.warning("분석 실패 %s: %s", p.key, e)
            h.missing.append(f"분석: {e}")

    return Context(date=today.isoformat(), profile=settings.profile, market=market_info,
                   holdings=holding_contexts, portfolio=portfolio, glossary_terms=GLOSSARY_TERMS)

"""AI가 쓴 analysis.json이 context.json의 숫자·신호를 벗어나지 않는지 검사."""
import re

from pydantic import ValidationError

from agent.report.schema import Analysis, Context

NUMBER_WITH_UNIT = re.compile(r"\$\s?(-?\d[\d,]*(?:\.\d+)?)|(-?\d[\d,]*(?:\.\d+)?)\s*(?:원|달러|%|배)")


def _numbers(obj) -> list[float]:
    if isinstance(obj, bool):
        return []
    if isinstance(obj, (int, float)):
        return [float(obj)]
    if isinstance(obj, dict):
        return [n for v in obj.values() for n in _numbers(v)]
    if isinstance(obj, list):
        return [n for v in obj for n in _numbers(v)]
    return []


def _matches(text_number: str, allowed: list[float]) -> bool:
    value = abs(float(text_number.replace(",", "")))
    decimals = len(text_number.split(".")[1]) if "." in text_number else 0
    tolerance = 0.5 * 10 ** (-decimals) + 1e-9
    return any(abs(value - abs(a)) <= tolerance for a in allowed)


def _texts(analysis: Analysis) -> list[str]:
    texts = [*analysis.summary, analysis.market_comment, analysis.portfolio_comment, analysis.watchlist_comment]
    for h in analysis.holdings:
        texts += [h.headline, h.reasoning, h.signal_downgraded_reason or "", h.disclosure_notes]
        for note in h.indicator_notes:
            texts += [note.value, note.plain]
    return texts


def validate_analysis(raw: dict, context: Context) -> tuple[Analysis | None, list[str]]:
    try:
        analysis = Analysis.model_validate(raw)
    except ValidationError as e:
        return None, [f"스키마 오류 {e.error_count()}건: {e.errors()[0]['loc']} {e.errors()[0]['msg']}"]

    errors = []
    expected = {h.ticker: h.signal for h in context.holdings if h.signal}
    got = {h.ticker: h for h in analysis.holdings}
    if set(got) != set(expected):
        errors.append(f"종목 불일치: 기대 {sorted(expected)} / 실제 {sorted(got)}")

    for ticker, h in got.items():
        want = expected.get(ticker)
        if want is None or h.signal == want:
            continue
        if want == "add" and h.signal == "hold" and (h.signal_downgraded_reason or "").strip():
            continue
        errors.append(f"{ticker}: 신호 변경 불가 ({want} → {h.signal})")

    allowed = _numbers(context.model_dump())
    for text in _texts(analysis):
        for match in NUMBER_WITH_UNIT.finditer(text):
            number = match.group(1) or match.group(2)
            if not _matches(number, allowed):
                errors.append(f"근거 없는 숫자: {match.group(0)}")

    return (None if errors else analysis), errors
```

def _num(value, digits=0):
    return "-" if value is None else f"{value:,.{digits}f}"


def _money(value, market="KR"):
    if value is None:
        return "-"
    return f"${value:,.2f}" if market == "US" else f"{value:,.0f}원"


def _signed_pct(value):

def auto_summary(context: Context) -> list[str]:
    counts = Counter(h.signal for h in context.holdings if h.signal)
    lines = [f"추가매수 후보 {counts['add']}개 · 일부매도 {counts['trim']}개 · "
             f"재검토 {counts['review']}개 · 보유 {counts['hold']}개"]
    if context.portfolio.rebalance:
        lines.append("리밸런싱 제안: " + ", ".join(
            f"{r.label} {r.amount_krw:,.0f}원 {r.action}" for r in context.portfolio.rebalance))
    else:
        lines.append("자산군 비중이 목표 범위 안에 있어요")
    disclosures = [d for h in context.holdings for d in h.disclosures]

    lines.append(f"최근 공시 {len(disclosures)}건{negative}")
    return lines

"""SMTP(SSL)로 HTML 메일 발송. 기본은 네이버 메일."""
import os
import smtplib
from email.message import EmailMessage


def send_email(subject: str, html: str, *, smtp_factory=smtplib.SMTP_SSL) -> None:
    host = os.environ.get("SMTP_HOST") or "smtp.naver.com"
    port = int(os.environ.get("SMTP_PORT") or 465)
    sender = os.environ["MAIL_FROM"]
    msg = EmailMessage()
    msg["Subject"] = subject
    msg["From"] = sender
    msg["To"] = os.environ.get("MAIL_TO") or sender
    msg.set_content("HTML 메일을 지원하는 메일 앱에서 열어주세요.")
    msg.add_alternative(html, subtype="html")
    with smtp_factory(host, port, timeout=30) as smtp:
        smtp.login(os.environ["SMTP_USER"], os.environ["SMTP_PASSWORD"])
        smtp.send_message(msg)

"""CLI: python -m agent {collect,publish,run}."""
import argparse
import json
import logging
import os
import sys
from datetime import date
from html import escape
from pathlib import Path

from dotenv import load_dotenv

from agent.collectors.dart import DartClient
from agent.collectors.prices import MarketData
from agent.config import load_holdings, load_settings, today_kst
from agent.delivery.email import send_email
from agent.report.context import ContextError, build_context
from agent.report.render import render_report
from agent.report.schema import Context
from agent.report.validate import validate_analysis

log = logging.getLogger("agent")


def _day_dir(args) -> Path:
    return args.out / args.date.isoformat()


def cmd_collect(args) -> Path:
    settings = load_settings(args.config_dir / "settings.yaml")
    holdings = load_holdings(args.config_dir / "holdings.yaml")
    dart = DartClient(os.environ["DART_API_KEY"], cache_dir=Path(".cache/dart"), today=args.date)
    context = build_context(settings, holdings, MarketData(), dart, args.date)
    day = _day_dir(args)
    day.mkdir(parents=True, exist_ok=True)
    path = day / "context.json"
    path.write_text(context.model_dump_json(indent=2), encoding="utf-8")
    log.info("context 저장: %s", path)
    return path


def cmd_publish(args) -> Path:
    settings = load_settings(args.config_dir / "settings.yaml")
    day = _day_dir(args)
    context = Context.model_validate_json((day / "context.json").read_text(encoding="utf-8"))

    notes, analysis = [], None
    analysis_path = day / "analysis.json"
    if analysis_path.exists():
        analysis, errors = validate_analysis(json.loads(analysis_path.read_text(encoding="utf-8")), context)
        if errors:
            notes.append("AI 분석 검증 실패 → 숫자 리포트로 대체")
            notes.extend(errors[:5])
    else:
        notes.append("AI 분석 없음 → 숫자 리포트")

    html = render_report(context, analysis, notes)
    preview = day / "preview.html"
    preview.write_text(html, encoding="utf-8")
    log.info("미리보기 저장: %s", preview)
    if not args.dry_run:
        send_email(f"{settings.report_subject_prefix} {context.date}", html)
        log.info("메일 발송 완료")
    return preview


def cmd_run(args) -> None:
    try:
        cmd_collect(args)
    except ContextError as e:
        if not args.dry_run:
            settings = load_settings(args.config_dir / "settings.yaml")
            send_email(f"{settings.report_subject_prefix} {args.date} 생성 실패",
                       f"<p>오늘 리포트를 만들지 못했습니다: {escape(str(e))}</p>")
        raise
    cmd_publish(args)


def main(argv: list[str] | None = None) -> None:
    load_dotenv()
    if hasattr(sys.stdout, "reconfigure"):
        sys.stdout.reconfigure(encoding="utf-8")
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")

    parser = argparse.ArgumentParser(prog="python -m agent")
    parser.add_argument("command", choices=["collect", "publish", "run"])
    parser.add_argument("--date", type=date.fromisoformat, default=None, help="기준일 (기본: 오늘, 한국시간)")
    parser.add_argument("--out", type=Path, default=Path("out"))
    parser.add_argument("--config-dir", type=Path, default=Path("config"))
    parser.add_argument("--dry-run", action="store_true", help="메일을 보내지 않고 preview.html만 생성")
    args = parser.parse_args(argv)
    args.date = args.date or today_kst()

    {"collect": cmd_collect, "publish": cmd_publish, "run": cmd_run}[args.command](args)


if __name__ == "__main__":
    main()
```
